Send rows

POST {{ send_url }}

  • rows: at most {{ max_rows|intcomma }} per call. For more, send a CSV / Excel file in the field file (mapped like the upload screen).
    • {% if dataset.is_snapshot %}
  • as_of: the As-of date of all rows (or _as_of_date in each row). Only the dates sent are replaced.
  • allow_big_delete: true to let it remove more than half the saved rows of a date.
    • {% else %}
  • mode: update (add new rows, change existing ones) or full (rows not sent are deleted; 0 rows is refused).
  • allow_big_delete: true to let a full refresh delete more than half the saved rows.
    • {% endif %}
  • dry_run: true only answers how many rows would be new / changed / deleted. Nothing is saved.
  • Problems → status 400 with a list like {"row": 14, "key": "1023", "problem": "Amount: “abc” isn't a number"}. Nothing is saved.
  • Another upload of the same dataset running → status 409: try again in a minute.

curl

curl -X POST "{{ send_url }}" \
  -H "Authorization: Bearer fd_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"{% if dataset.is_snapshot %}as_of": "2026-03-31{% else %}mode": "update{% endif %}", "rows": [{{ sample_json }}]}'

Python

import requests

answer = requests.post(
    "{{ send_url }}",
    headers={"Authorization": "Bearer fd_YOUR_KEY"},
    json={"{% if dataset.is_snapshot %}as_of": "2026-03-31{% else %}mode": "update{% endif %}", "rows": [{{ sample_python }}]},
    timeout=300,
)
print(answer.status_code, answer.json())
# 201 {"upload": 57, "added": 1, "changed": 0, "deleted": 0, "changes_url": "…"}

Read rows

GET {{ rows_url }}

  • {{ page_rows|intcomma }} rows a page, sorted by the key; page=2 for the next ones (the answer's next link has it).
  • Filters: column=value (exact; capitals ignored for text), column__contains=dom for text, column__from=… / column__to=… for numbers and dates.
    • {% if dataset.is_snapshot %}
  • One As-of date at a time: the latest, or as_of=2026-03-31.
    • {% endif %}
  • Decimals come as text (“1500.50”) so they stay exact; dates as 2026-03-31; Yes / No as true / false.

curl

curl "{{ rows_url }}?page=1" \
  -H "Authorization: Bearer fd_YOUR_KEY"

Python (all pages)

import requests

url, rows = "{{ rows_url }}", []
while url:
    page = requests.get(url, headers={"Authorization": "Bearer fd_YOUR_KEY"}, timeout=60).json()
    rows += page["rows"]
    url = page["next"]
print(len(rows), "rows")
