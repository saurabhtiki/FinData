# FinData
Reusable Django add-on: define a per-company financial database (masters, transactions, periodic reports) in PostgreSQL, then keep it updated from uploads. Shared rules: `../CLAUDE.md`.
Scope: `docs/project.md`. Current plan: `docs/plan.md`. File loading comes from `../data-core`.
Every phase: plan → grill-me questions → user confirms → build → test.
